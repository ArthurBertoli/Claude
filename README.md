# Claude Code Integration with VS Code & GitHub

This repository contains configuration and resources for using **Claude Code** integrated with **Visual Studio Code** and **GitHub**.

## What is Claude Code?

Claude Code is an AI-powered coding assistant that integrates directly into VS Code, providing:
- Real-time code generation and completion
- Code analysis and debugging
- Project exploration and understanding
- Multi-file editing and refactoring
- Code analysis and debugging
- Project exploration and understanding
- Multi-file editing and refactoring
- Direct integration with GitHub for version control

## Prerequisites

- **Visual Studio Code** (latest version)
- **Claude Code Extension** for VS Code
- **GitHub Account** (for repository integration)
- **Git** installed locally

## Installation & Setup

### 1. Install Claude Code Extension
1. Open VS Code
2. Go to Extensions (`Ctrl+Shift+X`)
3. Search for "Claude Code"
4. Click **Install**

### 2. Authenticate with GitHub
1. Open the Claude Code sidebar
2. Click on the GitHub icon
3. Authorize Claude Code to access your GitHub repositories

## Usage

- Click the Claude Code icon in the sidebar
- Start typing your requests
- Claude Code will analyze and respond
